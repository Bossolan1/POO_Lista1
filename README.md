# 🧾 Exercícios de Programação Orientada a Objetos

## 💻 Sobre o projeto

Este repositório contém as implementações dos **exercícios de POO** propostos em aula. Até o momento, concluí os exercícios de **1 a 6**.

Os exercícios **7 e 8 ainda estão em andamento**, mas preferi entregar até onde consegui — com sinceridade e transparência, do que apresentar algo incompleto ou mal testado.

---

## 📚 Lista de Exercícios

### ✅ Exercícios implementados

1. **Biblioteca:** livros com título, autor e ano. Permite cadastrar e listar livros.
2. **Música online:** usuário com playlists; cada playlist com várias músicas.
3. **Loja virtual:** cliente com pedidos, pedidos com itens, calcula valor total.
4. **Clínica médica:** paciente com prontuário, médico responsável.  
   ⚠️ *Ainda não adaptei para suportar múltiplas anotações médicas, só uma por enquanto.*
5. **Instituição de ensino:** cursos com turmas; turma com professor e vários alunos.
6. **Empresa de transporte:** ônibus com rotas, rotas com paradas, motoristas vinculados à frota.

### ⏳ Em andamento

7. **Jogo:** jogador com inventário (itens e armas); inimigos com armas equipadas.
8. **E-commerce:** cliente com carrinho de compras; carrinho gera pedido com pagamento.

---
